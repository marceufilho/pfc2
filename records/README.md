# Records

Small records of the runs behind the reported results. The raw runs (observations, logs, emitted C, model replies)
are not published.

- `design/DESIGN.md`, `design/AMENDMENTS.md`: experiment definitions and every later change, dated.
- `design/preregistration-20261118/`: the bundle of 2026-11-18 with its checksums. Dates are local.
- `runs/<name>/`: for each sealed run on candidate `pfc2-v3`, its configuration, environment, summary, tables,
  schema and manifest (SHA-256 of every file of the run, including the unpublished ones).
- `classifications/`: the per-mutant and per-contract classifications that the reported counts come from. They
  were reviewed on a sample only; each file says who labelled it.
