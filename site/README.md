# PFC2 site

Astro + Starlight, static, for GitHub Pages under `/pfc2/` (change `site` and `base` in `astro.config.mjs` if the
repository is published elsewhere).

| Written by hand | Generated by `tools/site_data.py` (never edit) |
| --- | --- |
| `src/content/docs/index.mdx`, `playground.mdx` | `src/content/docs/docs/*.md` from `docs/` |
| `src/components/Playground.astro`, `src/lib/*.ts`, `src/styles/*.css` | `src/content/docs/examples.md` from `examples/` |
| `public/engine/worker.js` | `public/data/programs.json`, `public/engine/pfc2-bundle.json` |

```console
$ make site-data                    # from the repository root
$ make site-data SITE_ARGS=--check  # compare with a fresh build; writes nothing
$ make site-build                   # site/dist
$ make site-test                    # browser tests (once: pnpm --dir site exec playwright install chromium)
```

The playground runs the same Python code as the `pfc2` command on Pyodide, with the Z3 WebAssembly wheel pinned
in `engine.lock.json`. One declared difference: a fixed integer layout (32-bit `int`, 64-bit `long`) instead of a
clang query. `tests/site.spec.ts` runs every example in Chromium and requires the result of the native run.
